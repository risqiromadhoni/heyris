# I18n Test Plan

## Application Overview

The English site lives under `/en`, and the Indonesian site keeps its paths with no prefix. `src/pages/en/index.astro` renders `HomePage` with `locale="en"`, and the English writing and notes indexes render their page slices with the same locale. Each English page is an English document (`lang="en"`).

Entries without an English version are listed in the English indexes and on the English home with their Indonesian text. Their row links to the Indonesian post, with `hreflang="id"` on the link and `lang="id"` on the title and summary.

The ID / EN toggle (`LanguageToggle`) sits in the top bar of the index pages (`SiteTopBar`) and of the post and note pages (`ArticleTopBar`, on the right). It links to the same page in the other language when that page exists, and otherwise to the other language's index. The home page has no top bar and no toggle. The accessibility target is WCAG 2.2 Level AA.

## Test Scenarios

### 1. English home

**Seed:** `e2e/seed.spec.ts`

#### 1.1. Loads the English home in English

**File:** `e2e/i18n/loads-the-english-home-in-english.spec.ts`

**Steps:**
  1. Open the English home at /en
    - expect: The html element has lang="en"
    - expect: The document title is "Risqi Romadhoni"
    - expect: The bio has the radio options "Short" and "Long"
    - expect: The level-2 headings "Writing" and "Notes" are visible

#### 1.2. Has no WCAG 2.2 AA violations on the English home

**File:** `e2e/i18n/has-no-wcag-2-2-aa-violations-in-english.spec.ts`

**Steps:**
  1. Open the English home at /en
    - expect: The level-2 heading "Writing" is visible
  2. Run an axe scan limited to WCAG 2.2 Level A and AA rules
    - expect: The scan reports no violations

#### 1.3. Has no WCAG 2.2 AA violations on the English home in dark mode

**File:** `e2e/i18n/has-no-wcag-2-2-aa-violations-in-english-dark-mode.spec.ts`

**Steps:**
  1. Set the saved theme to dark before the page loads, then open the English home at /en
    - expect: The html element has the dark class
    - expect: The level-2 heading "Writing" is visible
  2. Run an axe scan limited to WCAG 2.2 Level A and AA rules
    - expect: The scan reports no violations

### 2. Language toggle

**Seed:** `e2e/seed.spec.ts`

#### 2.1. Switches between Tulisan and English Writing

**File:** `e2e/i18n/switches-between-writing-and-english-writing.spec.ts`

**Steps:**
  1. Open the writing index at /tulisan
    - expect: The html element has lang="id"
  2. Press EN in the top bar
    - expect: The URL ends with /en/writing
    - expect: The html element has lang="en"
    - expect: The level-1 heading "Writing" is visible
  3. Press ID in the top bar
    - expect: The URL ends with /tulisan
    - expect: The html element has lang="id"
